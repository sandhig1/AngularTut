• What is rxjs?
    • RXJS (Reactive Extension for JavaScript) is a core library used by the angular framework to manage asynchronous operations, event handling & data stream.
    • Instead of relying on standard Javascript promises, Angular treats event Like,
      HTTP Response, Form Inputs, & route changes as continuous streams handled via RXJS Observables.
  • What are the core concept of rxjs?
    • Core concept of rxjs are :
      • Observable
        • A data producer that emits values
      • Oberver/Subscriber
        • The consumer that listens to objservable stream via the .subscriber() method.
      • Operators
        • Operators are the functional methods used within .pipe() to transform, filter, or combine data streams.
      • Subject/BehaviourSubject
        • Subject and BehaviourSubject are special type of observables that can acts as both Observable (Means you can listen/subscribe to it using .subscribe method)
          and also as observer (Means it can emits value to the subscriber using .next() method)
