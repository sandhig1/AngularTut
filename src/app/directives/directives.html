• What isDirectives in Angular?
    • Directives in Angular are special type script class derived from @directive that allow you to
      • Attach custom Behaviour
      • Alter Appreance
      • Modify the layout of the DOM by adding or removing elements
  • What are different type of directives in Angular?
    • Angular offer primarily 3 types of directives :
      • Component Directive:
        • Components are the building block of an angular application.
        • Component are directives with a template
        • The group User interface (UI), Style (Css) and backend code logic
        • It creates entirely new resuable UI modules
      • Attribute Directive:
        • There attributes changes the appreance, behaviour or charactereistic of an DOM Element, component or other directives.
        • They are added to elements much lik HTML attributes
        • Commonly used Attribute Directies are
          • NGClass : It dynamicall appends multiple css classeds simultaneously
          • NGStyle : It change the inline styes of an element
          • NGModel : It enables two way binding on a form entry node
      • Structural Directives:
        • It changes the physical layout of the DOM by adding or removing or re-ordering the html element
        • They are recognized by (*) asterix symbol
        • Common Structural Attributes are
          • *ngif
          • *ngfor
          • *ngswitch
