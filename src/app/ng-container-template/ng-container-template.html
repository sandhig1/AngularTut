• What is <ng-Container> & <ng-Template> in Angular?
    • <ng-Container> & <ng-Template> in Angular are specialized elements used to manage template logic and structure without adding unnecessary element.
    • <ng-Container> evaluate and render its content immediately while
      <ng-Template> define a lazy-loaded block of HTML which remains hidden unless explicitly rendered by any control flow or directly
  • Explain <ng-Container>?
    • <ng-Container> is an structural placeholder
    • You should use it when you need a wrapper to attach logic logic but you do not want to pollute the layout with an extra wrapper element like div that will be visible in DOM
  • Explain <ng-Template>
    • <ng-Template> is a reusable blueprint
    • Angular complier process the content inside <ng-template> but doesnot show anything in the screen untill you explicitly tell angular to draw it.
