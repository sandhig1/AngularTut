• What is Facade?
    • Facade is an structural pattern that is used as angular service to act as a single point of entry between the components and complex background systems like API, Business Layer.
    • Its an abstraction layer that stops component to access the inner higher level complex APIs or data.
  • What are the advantages of Facade?
    • Following are the advantages of Facade :
      • Simpler Component
        • It keep you component simple, readable and strictly restricted to managing presentation layer logic.
      • Decoupled Architecture
        • As the data, business layer & apis shifts, you need to only write the interiof of facade service & your component remained untouched.
      • High Reusability
        • Multiple components can consume the same facade methods without repeating tedious API calling or subscription chain.
      • Easier Testing
        • Testing components become easier as you need to mock one simple facade service instead of mocking complex http request and nested state system.
  • When you should avoid it?
    • You should avoid facade for small apps or simple CRUD application where component simply fetchs a resource from a single API service.
  • Syntax of Facade
    • ng generate component <Facade Name>
