• What Signal in Angular?
    • Signal in Angular is a reactive wrapper around a value that automatically nofifies interested consumers whenever that value changes./li>
    • It allow angular to gradually track state changes across your application, triggering targeted updates only where needed instead of scanning the entiry component
    • You can read a signal's value by calling the getting function, which allow angular to track where the signal is used
  • What are different type of Signal in Angular?
    • There are 2 types of Signal :
      • Signal (Writable):
        • These signals store the actual state.
        • Writable Signal value modified directly by using dedicated functions like set or update.
      • Computed Signal:
        • These signal read-only variables, whose values are derived dynamicall from the other signal.
        • Its values changes automatically when the dependency signal's value change
  • What are effects?
    • Efects are are function that executes side effects whenever their observed value changes.
    • These funtions are automacally called whenever there is changes in the value of signal variable to whole this function is observing
  • How to convert Writable Signal to readd only?
    • Writable Signal provide a asReadOnly() method that return a readonly version of the signal.
    • This is useful when you want to expose signal value to the consumer without allowing them to modify the signal value directly
    • You can modify the readonly variable value by modifying the value of actual writable signal variable
