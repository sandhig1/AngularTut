• In Angular, What are Subject and BehaviorSubject?
    • Subject and BehaviorSubject are special types of observables of RXJS Library,
      used to share data and manage state across different parts on application.
    • Unlike standard observable, which are unicast (each subscribers get a fresh, iolated execution),
      Subject and BehaviorSubjects are multicast, this mean they broadcast the same data stream to multiple subscribers simultaneously.
    • They can act both as an Observable (you can subscribe to them) and Observer (You can manually feed values into them using .next()).
  • Difference between Subject and BehaviorSubject?
    • Difference between Subject and BehaviorSubject are :
      • Initial Value
        • Initial value is not required while declaring Subject
          Initial value is strictly required while decaring BehaviorSubject.
      • On Subscription
        • Subscriber of Subject receives nothing untli a new value is entitled
          Subscriber of BehaviorSubject immediatly receives the last emitted value (or the initial value).
      • Memory
        • Subject does not store or remember past value
          BehaviorSubject stores the lates value in memory.
      • Synchronous Access
        • You can not check the value of Subject without subscribing
          You can fetch the value of BehaviorSubject instantly using .getValue() or .value.
      • Primary Use Case
        • Signal should be used where your dont want to store the history or current value
          while BehaviorSignal should be used where you want to store the history or current value.
