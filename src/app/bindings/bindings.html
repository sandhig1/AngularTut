Binding

  • What is Binding in Angular?
    • Bindings allow displaying data from ts file to html
  • What are different type of Bindings in Angular?
    • There are 2 types of Bindings in angular:
      • One way Binding
      • Two way Binding
  • What is One Way Binding in Angular?
    • One way binding in Angular is binding which allow display value only from ts file to html file
    • One way binding is used for
      • Displaying value only from ts file to html file
      • Formating variable values in html
      • Comparing variable values in html
      • Note: You cannot assign value to the variable in html
  • What are different type of One Way Binding in Angular?
    • There are 3 types of one way binding:
      • Interpolation
      • Property Binding
      • Event Binding
