• What is Reusable Components in Angular?
    • Reusable components in Angular are self-contained, generic block of User Interface and code, designed to use in multiple times in different parts on an Angular Application.
    • Instead of using default repetitative html elements, You can design your own customized element using reusable component and can pass various configuation settings
    • Reusable components are also called "Dumb or Presentation Components" because it rarely manage any complex business type or fetch data directly.
    • Reusable components are heavily rely on its parent component to tell them what to display.
  • What are different type of mechanism used to build reusable component in Angular?
    • Angular offere primarily 3 mechanisms to make the component reusable and dynamic :
      • Data Input (@input()):
        • It allows parent component to pass data to the child component
      • Data Output (@output()):
        • It allows child component to emit custom events upto the parent component when a user interacts with it
      • Content Projection (<ng-content></ng-content>) :
        • It allows parent component to inject custom HTML or other components directly into a dedicated slot with in the reusable compopnent template.
