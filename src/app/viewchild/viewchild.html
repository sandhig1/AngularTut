• What is ViewChild in Angular?
    • ViewChild in Angular is a query mechanism used to get a reference to an element, directive, or a child component instance inside a components's own HTML Template.
    • Its like angular's native, safe alternative to JavaScript's native document.getElementByRefId or queryselector.
    • It gives you direct way to programmatically access and manupulate elements.
  • Why do we use ViewChild?
    • Access Child Component:
      • It call public method or read property of component directly.
    • Reference DOM Element:
      • It Target/Reference HTML Elements directly to apply focus, trigger scrolling, or measure dimensions.
    • Interact with Directives:
      • To read vialue or run logic from custom directives applied with in the template.
  • What are Different ways of implement ViewChild?
    • Angular offere primarily 2 ways of implementing ViewChild :
      • Traditional Decorator Approach:
        • By using @ViewChild property decorator.
      • Modern Signal Approach:
        • In recent viewson of angular, Signal based view queries provided reactive, Type Safe Queries without life-cycle hook coplexities.
  • Note : While accessing Component you should directly refer to the Component Tag and initialize the component class in ngAfterViewInit event
