• What is Interceptor in Angular?
    • An Angular interceptor is a powerful middleware tool that inspects, transforms or handles HTTP requests &
      response globally before they reach the server or your application component
  • What is interceptor use for in Angular?
    • Angular interceptor is used for :
      • Authentication:
        • It automatically attach a Bearer Token or authorization headers to every outgoing request.
      • Global Errors Handling:
        • It catches newtwor errors globally & format user-friendly alearts.
      • Loading Spinner:
        • It trigger global UI spinners when network operations are active.
      • Logging:
        • It bechmark response time & audit API Request
      • Caching & Mocking:
        • It return mock data or cached responses locally to save band width.
